# Instagram Clone App


The Instagram Clone App is built using Flutter and Firebase.

The Instagram Clone app is an mobile app that implements an Instagram like photo and video sharing with Riverpod. User can also like and comment on posts. Social sign-ins such as Facebook and Google are used for authentication. Firebase Firestore is used to store our documents and Firebase Storage to store photos and videos

This app was created to practice Flutter and Riverpod state management.


## Features

- Google Authentication
- Facebook Authentication
- Upload Photos/Videos
- Like Posts
- Comment Posts
- Manage Posts

## Technology

**Language:** Dart

**UI:** Material UI

**Firebase**
* Firebase Authentication
* Firestore Database
* Firebase Storage

**State Management:** Riverpod 2.0


**Other Components Used**
* (Check [`pubspec.yaml`](https://github.com/prabeshpudasaini/Instagram-Clone-Course-App/blob/main/pubspec.yaml) for more)


## Installation

1. Download or clone project and open the project in VS Code
2. Create Firebase Project
3. Enable Google and Facebook Authentication
4. Setup Firestore Database
5. Setup Firebase Storage
6. Set Firestore Rules
7. You can use FlutterFire to create a firebase project easily
8. Run flutter get to download all dependencies
9. Connect your Android phone or use the emulator to start the application
